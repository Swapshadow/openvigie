# Security policy

## Reporting a vulnerability

Please do not disclose exploitable security issues in a public GitHub issue.

Use GitHub's private **Report a vulnerability** option in the repository's
Security tab. Include:

- the affected version or commit;
- a clear description of the impact;
- minimal reproduction information;
- suggested mitigations, if known.

Do not include real credentials or target data. A maintainer will acknowledge
the report and coordinate remediation and disclosure.

## Scope

Reports about OpenVigie's own code, deployment configuration, collectors, data
integrity, and unsafe rendering of third-party content are in scope.

Reports describing vulnerabilities in monitored vendor products should be sent
to the relevant vendor PSIRT or appropriate CERT.
